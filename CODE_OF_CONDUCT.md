# Code of Conduct

Gopad is a small open-source project and aims to be a welcoming, practical
place to collaborate.

Participants are expected to:

- be respectful and assume good faith;
- focus feedback on the work, not the person;
- make room for different backgrounds and experience levels; and
- accept correction without hostility.

Harassment, discrimination, threats, personal attacks, and deliberate
disruption are not welcome. Report a concern privately to the repository
maintainers through the contact route in [SECURITY.md](SECURITY.md).
